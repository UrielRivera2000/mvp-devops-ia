# Fuentes sintéticas del PoC DevOps

Todos los datos son ficticios y se usan exclusivamente para el PoC.

- `knowledge/*.md`: base técnica para `buscar_conocimiento_tecnico`.
- `jira_incidentes_normalizados.csv`: histórico sintético para `buscar_incidentes_historicos`.
- `jira_api_export_sintetico.json`: ejemplo REST-like de Jira Cloud v3.
- `golden_cases.csv`: tres pruebas mínimas.
- `jira_incidentes_ficticios.xlsx`: libro de revisión humana (se genera por separado).

Los runbooks son material didáctico sintético, no documentación oficial de Kubernetes, SonarQube, Docker ni Atlassian.
